# Historical results

This directory preserves the Romeo cluster campaign present at revision `d533cab` on 2026-03-31. These timings and figures are **historical, not remeasured**. They are excluded from the maintained README's quantitative claims.

New local measurements, warmups, machine metadata and validation outputs live in [bench/results](../bench/results/). See [the archive catalogue](../docs/archive.md) for the relationship between the original CSV files, scripts, PNGs and PDF reports.
